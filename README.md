2. Why is a perfect fingerprint system impossible? A perfect fingerprint system is impossible because the same finger gives a slightly different scan every time, depending on position, pressure and how dry or wet it is. Since genuine and impostor scores can overlap, lowering one error rate usually increases the other, so no system can reach zero errors.
